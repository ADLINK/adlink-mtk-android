This repo is dedicated to the ADLINK MediaTek products. Here you can find the Android BSP.

You can follow the same steps to build your own customized BSP based on your interests.

| Product    |                    Hardware Documentation                    |
| :--------- | :----------------------------------------------------------: |

# 2. Supported Android Versions

|  Android Version   |      Supported Products                                |
| :--------- | :----------------------------------------------------------: |
| Android 16 | [OSM-MTK520](https://github.com/ADLINK/adlink-mtk-android/tree/Android-16) |

# 3. ADLINK Supported Patches

- Patches for ADLINK MediaTek products are maintained in the `Patches/<mtk-variant>` directory of their respective Android version branches.
- The patches that we created and have are based on the MediaTek Android SDK.
